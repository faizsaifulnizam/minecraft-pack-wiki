# Getting started

> Development snapshot: **dev-0.5-20261015**. Minecraft **1.21.1**, NeoForge **21.1.250**. The pack is still changing.

## Before you start
Use the same pack revision as your friends. This handbook describes a developing local baseline, not a released server pack or a tested import download. Do not update individual mods just to match an online tutorial.

## Find things before memorising recipes
Open an inventory screen and try [recipe search](https://faizsaifulnizam.github.io/minecraft-pack-wiki/guides/recipe-search/). The saved EMI layout places search on the right, with favourites on the left. Exact recipe ingredients and recipe-viewer categories still need runtime checks, so this handbook does not replace the current in-game viewer.

## Choose your first project
- Want searchable storage? Read [AE2 starter preparation](https://faizsaifulnizam.github.io/minecraft-pack-wiki/guides/ae2-starter/).
- Want machines? Read [MI Forge Hammer and bronze](https://faizsaifulnizam.github.io/minecraft-pack-wiki/guides/mi-starter/).
- Want magic, Tensura or SoloCraft? Check the [pack map](https://faizsaifulnizam.github.io/minecraft-pack-wiki/pack-map/) first. Their complete starting flows are not yet documented here.

## Saved controls to check
| Action | Saved binding | Limit |
|---|---|---|
| EMI search | Ctrl+F | Inventory/recipe context; JEI also has overlapping actions. |
| Recipes / uses | R / U | Item context; not a global command. |
| Xaero minimap settings | Y | Saved, not demonstrated in this edition. |
| New Xaero waypoint | B | No personal waypoints are included. |
| Map | M | Both Xaero and FTB Chunks map bindings use M; resolve in Controls if necessary. |

No key overlap is called a confirmed bug without testing. The saved FTB minimap is off; that does not disable claims or protection. Inventory Profiles Next has its overlay/editor/settings buttons hidden, so the lack of those buttons is expected saved UI state.

## Keep comparisons consistent
Saved settings are GUI scale 2, render distance 12, simulation distance 6, VSync off and a 120 FPS cap. Memory override is 1024–8192 MiB. These are observed settings, not minimum hardware requirements or a performance guarantee. Leave someone else's instance unchanged unless they want a setting changed.

[Display and recipe troubleshooting](https://faizsaifulnizam.github.io/minecraft-pack-wiki/troubleshooting/) lists what to check without changing the mod stack.
