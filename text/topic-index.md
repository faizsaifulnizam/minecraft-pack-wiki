Installed presence does not mean those guides or integrations are complete. Use the pack map to identify a system; missing instructions are not proof a feature is absent.

Search matches literal terms, aliases and exact identifiers. Try a short mod/item name rather than expecting semantic answers to a long question. Full-spoiler search is a separate explicit option.
