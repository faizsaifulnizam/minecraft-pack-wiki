## Prerequisites
A character already in the pack, access to your Controls menu, and a safe place to inspect menus. No command permissions, reset item, dungeon entry, or deliberate death is required for these inspection tasks.

## Steps
1. For SoloCraft, begin with [Open Panel and the quest checklist](https://faizsaifulnizam.github.io/minecraft-pack-wiki/guides/solo-start/). You can identify the named control and current screen without assuming that Tensura progression unlocked it. If the panel is unavailable, the starter guide names the missing acquisition evidence rather than inventing a fix.
2. For Tensura, begin with [the built-in archive and evolution display](https://faizsaifulnizam.github.io/minecraft-pack-wiki/guides/character-tools/) if you already have access to the character screen. This path now identifies the candidate core’s Status Menu control and a noncommitting inspection checkpoint. Initial access requirements remain unresolved by text resources.
3. Treat [the integration layer](https://faizsaifulnizam.github.io/minecraft-pack-wiki/reference/character-integration/) as a separate explanation of explicit shipped declarations. Do not transfer a rank, skill award, resource amount, or gate from one system to the other merely because both are installed.
4. For a returning SoloCraft character with crystals already obtained, [craft the two documented items](https://faizsaifulnizam.github.io/minecraft-pack-wiki/guides/solo-workbench/). This is a material-to-result path, not a promised source of starting crystals or hunter awakening.

## Expected result
You know which progression system owns your current task and which evidence supports its instructions. A menu inspection or craft is not proof of awakening, reincarnation, or cross-system award continuity.

## Common failures
- An advancement tree appears to demand another advancement first: a display parent is not an awarding gate. The selected SoloCraft awakening advancement uses an impossible trigger; its code-driven award path has not been traced.
- Advice says to die, reset, or spend a rare item to fix a menu: do not follow it from this chapter. No reversible reset or reliable recovery has been established for this snapshot.
- A helper screen offers a destination: a displayed branch is not proof that you can perform it now. Read its current requirement text; the full notes distinguish requirement categories from actual per-race gate proof.
