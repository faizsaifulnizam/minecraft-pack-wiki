# Find the right graphics or documentation system

> Development documentation snapshot: **dev-0.5-20261015-r2**. Minecraft **1.21.1**, NeoForge **21.1.250**. Static records are not effective settings or runtime acceptance.

Use this reference to route a question, not as an install list. Archive metadata establishes recorded presence and identity only. Saved state, shipped documentation, effective behavior and runtime acceptance remain separate.

## Books are not the same as libraries
Patchouli, Modonomicon and GuideME are recorded inventory entries awaiting framework-role verification. The retained identity records do not establish their documentation roles or independent progression systems. Modonomicon has archive filename/release label **1.120.7**, while the retained manifest reports **Implementation-Version 1.110.0** (`modonomicon-1.21.1-neoforge-1.120.7.jar!META-INF/MANIFEST.MF#Implementation-Version`). This unresolved discrepancy establishes neither a wrong installed build nor an effective runtime version; neither token is normalized. Their presence does not prove that a particular book exists, how to obtain it, or which key opens it. Check the content system's guide instead of crafting a guessed generic “guidebook.”

- For AE2, the [starter outline](https://faizsaifulnizam.github.io/minecraft-pack-wiki/guides/ae2-starter/) identifies shipped guide content; it is not proof of a powered storage network.
- For Ars, the [first spell guide](https://faizsaifulnizam.github.io/minecraft-pack-wiki/guides/ars-first-spell/) distinguishes its documentation item from the spellcasting book. Do not consume your only documentation copy on an assumption that all books are interchangeable.
- For Occultism and Nature's Aura, use their [first workbench](https://faizsaifulnizam.github.io/minecraft-pack-wiki/guides/occultism-first-workbench/) and [first garden](https://faizsaifulnizam.github.io/minecraft-pack-wiki/guides/natures-aura-first-garden/) pages, retaining their stated geometry and runtime limits.

Inventory identity citations: `Patchouli-1.21.1-93-NEOFORGE.jar!META-INF/neoforge.mods.toml`; `modonomicon-1.21.1-neoforge-1.120.7.jar!META-INF/neoforge.mods.toml`; `guideme-21.1.19.jar!META-INF/neoforge.mods.toml`. These citations establish identities, not book-opening mechanics. The linked content guides carry their own mechanic-specific evidence. This reference does not assign every shipped book to a framework.

Dependency libraries supply implementation support; they do not automatically need player crafting tutorials. Do not remove a library because it has no player-facing menu. Library necessity for a specific error requires an exact dependency/error trace, not a filename guess. Likewise a resource path containing “book” can be a model or registry rather than guide prose.

## Disabled means no enabled route
CIT Resewn and More Culling are recorded **disabled**, not suggested fixes or available active controls. Their metadata locators are `citresewn-neoforge-1.21.1-0.jar.disabled!META-INF/neoforge.mods.toml` and `moreculling-neoforge-1.21.1-1.0.8.jar.disabled!META-INF/neoforge.mods.toml`. Do not enable them from this page. Entity Culling is a different recorded active archive; its presence does not change More Culling's disabled status.
