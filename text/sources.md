# Sources and evidence

> Development snapshot: **dev-0.5-20261015**. Minecraft **1.21.1**, NeoForge **21.1.250**. The pack is still changing.

## Status labels
| Label | Meaning |
|---|---|

## Baseline and reproducibility
Baseline ID: `dev-0.5-20261015`. The UTC inventory was captured late on 14 October; the snapshot ID uses its 15 October Singapore date. Exact versions and SHA-256 identities are retained in the safe baseline payload. Public content does not include local absolute paths, raw configs, logs, saves or mod binaries.

Archive citations use `archive.jar!internal/path`. They point inside the installed version, not to a claim about the newest upstream release. They are not downloadable JAR links and do not grant redistribution rights.

The first map independently rechecked all 120 active archive hashes, 112 sampled data/text records and 19 selected-settings source hashes. It did not test a game session, final recipe registry, multiplayer compatibility, performance or complete progression. A snapshot can become stale as development continues.

## Updating safely
Capture a new private inventory after approved pack changes, compare added/removed/changed archives and selected settings, then review affected pages. Never overwrite curated guides just because a file hash changed. Re-export the text editions after an accepted content change. An unreviewed automated refresh is not part of this edition.
